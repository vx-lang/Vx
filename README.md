# CLA signatures

This branch holds nothing but the record of who has signed the
[Vx Contributor License Agreement](https://github.com/vx-lang/Vx/blob/main/docs/CLA.md).

`signatures/version1/cla.json` is written by the CLA bot in
`.github/workflows/cla.yml`. It is not edited by hand: an entry is added when a contributor
posts the signing sentence on a pull request.

The branch is an orphan, with no shared history with `main`. That is deliberate, so signature
commits stay out of the history of the code.
