# Implement Custom `vx` MLIR Dialect

This plan outlines the first major milestone of the Vx v3.0 Roadmap: introducing a custom MLIR dialect to model heterogeneous topologies natively.

## Goal

Establish the boilerplate and build-system integration for a native `vx` MLIR dialect using TableGen (`.td`), C++ implementation, and Rust FFI. This replaces the reliance on Apple C-FFI shims and unlocks native hardware kernel generation in MLIR.

## Proposed Changes

### 1. TableGen Dialect Definition

We will introduce `include/VxDialect.td` to define the dialect via MLIR's Operation Definition Specification (ODS).

#### [NEW] \[include/VxDialect.td\](file:///Users/adityak/go/Vx/include/VxDialect.td)

- Define the `Vx_Dialect` record.
- Define a base class `Vx_Op` for operations.
- Introduce a placeholder operation (e.g., `Vx_SpawnOp` or `Vx_PrintOp`) to verify it compiles and loads correctly.

### 2. C++ Implementation & FFI Wrapper

Since `melior` uses the MLIR C-API, we need to build the C++ dialect and expose a C-compatible registration function.

#### [NEW] \[src/dialect/VxDialect.cpp\](file:///Users/adityak/go/Vx/src/dialect/VxDialect.cpp)

- `#include` the headers generated by `mlir-tblgen`.
- Implement `VxDialect::initialize()`.
- Expose an `extern "C" void registerVxDialect(MlirContext ctx)` function to insert the dialect into the raw MLIR context.

### 3. Build System (`build.rs`)

The build script needs to invoke TableGen and compile the C++ dialect into our Rust binary.

#### [MODIFY] \[build.rs\](file:///Users/adityak/go/Vx/build.rs)

- Add a step to run `mlir-tblgen -gen-dialect-decls` and `-gen-dialect-defs` on `VxDialect.td`.
- Compile `src/dialect/VxDialect.cpp` using the `cc` crate, including the generated `.inc` files from the `OUT_DIR`.

### 4. Rust Integration

We will bind the C-FFI function in our Melior code generator to load the dialect dynamically.

#### [MODIFY] \[src/melior_codegen.rs\](file:///Users/adityak/go/Vx/src/melior_codegen.rs)

- Declare `extern "C" { fn registerVxDialect(ctx: mlir_sys::MlirContext); }`
- Call this function using `context.to_raw()` right after creating the `melior::Context`.
- Print a debug message confirming the `vx` dialect is registered.
