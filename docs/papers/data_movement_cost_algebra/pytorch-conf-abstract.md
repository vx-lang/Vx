Submission Title: Beyond Operator Fusion: Graph-Routed Topology Awareness in PyTorch Inductor

Abstract (long):
As deep learning hardware scales into complex, asymmetric clusters, managing data movement has outgrown traditional compiler heuristics. Modern frameworks like PyTorch rely heavily on operator fusion via `torch.compile` to mitigate memory transfers locally. However, when executing workloads across 3D Parallelism boundaries (Tensor, Pipeline, and Data Parallelism), modern graph compilers treat inter-device memory homogeneously. They lack an intrinsic mechanism to solve optimal multi-hop routing paths across jagged hardware hierarchies, forcing infrastructure teams to manually tune pipelines and hardcode communication paths.

This presentation diagnoses the data movement bottlenecks inherent to Large Language Model (LLM) decode phases and introduces a novel architectural framework to resolve them: the Data Movement Cost Algebra. By formalizing a cluster's hardware topology as a weighted directed graph, this architecture injects a deterministic routing solver directly into PyTorch Inductor's intermediate representations (IR). The presentation outlines a time-aware optimal pathfinding engine—progressing from initial shortest-path routing to generalized Multi-Commodity Flow (MCF)—designed to supersede naive `DTensor.redistribute()` collective fallbacks. This approach maps optimal data paths not just horizontally across NICs, but vertically through a single node's memory hierarchies (SRAM to HBM to Host DRAM).

Finally, the talk details the design of a closed-loop Profile-Guided Optimization (PGO) pipeline that bridges deep learning serving runtimes (such as vLLM) with compiler backends. By mapping live telemetry—such as dynamic link congestion, NVLink saturation, and PCIe queue depths—back into the compiler as a structured graph manifest, Inductor's scheduling and buffer allocation decisions can be dynamically grounded in real-world hardware states. Attendees will leave with a prescriptive, algorithmic look at the next evolution of topology-aware codegen for distributed LLM architectures.
