Notes on building Vx — what the compiler does, what it refuses, and what it got wrong along the way.

  • Many short tapes 23 September 2026

    Mainstream languages assume one memory that never runs out: Turing's tape with a pointer size on it. An H100 node has host DRAM, 80 GiB of HBM, 50 MiB of L2 and 132 copies of 228 KiB of shared memory. Vx reads that list as a machine file and checks programs against it.

  • float * of C/C++/Rust Fails to Distinguish Host DRAM from GPU HBM 23 September 2026

    malloc and cudaMalloc return different memory, and C, C++ and Rust give both the same type. The libraries each built the missing type, and lose it again at every raw pointer. In Vx the memory space is part of the type.

  • Reverse engineering trait implementation to fix the Vx's 22 September 2026

    Two impls of one trait collided on one mangled name, and picking between them looked like a language design decision. Compiling the same program in Rust showed that Rust makes no such decision: it infers the argument's type, and defaults a bare integer literal to i32.

  • The library that only worked on the machine that built it 22 September 2026

    Vx 0.0.1 could not run hello-world on any machine except the one that built it. Both macOS libraries recorded the release runner's own directory, and the smoke test passed throughout because it ran on that runner. Three more bugs were hiding behind it.

  • The 43 gigabytes that are never there 21 September 2026

    Add up every tensor a Llama-2-7B prefill puts on the GPU and you get 58.93 GiB, which does not fit a 40 GiB A100. The tensors resident at the same time peak at 15.94 GiB. The compiler computes the peak from the program's block structure, before the card is booked.

  • Tiles, without a tile type 21 September 2026

    Can Vx be used for tile-based GPU programming, the way NVIDIA's cuTile is? A block loop, a tensor in Memory::SMEM and two barriers already compile to PTX with shared storage and bar.sync. The tile algebra does not exist.

  • What writing core taught the compiler 21 September 2026

    A week ago Vx had no core library. Now it has six modules of it, a random-number library, and the compiler fixes that writing them forced — a method that dispatched differently between runs among them. Every line is Vx, with no extern in it.

  • The NUMA that wasn't there 12 September 2026

    A CPU's NUMA domains are the same relation as two GPUs on a node, so the compiler already knew how to price them. It predicted a remote access costs 2.26× a local one and the hardware said 2.35× — after we threw away a day of measurements taken on a machine that reports two nodes it does not have.

  • What a pointer forgets 10 September 2026

    A function stages a tensor to the GPU and returns it. In C++ the return type is float * and the fact is gone at the boundary. In Vx it is part of the type.

    The first release. What the compiler checks, what it runs on, and the parts that are honestly not built yet.
